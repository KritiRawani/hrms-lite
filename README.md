# HRMS Lite Training Repository

This is an authorized training repository created for GitHub workflow demonstrations.

## Project Overview

HRMS Lite is a sample employee attendance and workforce management application used for training and workflow practice.

## Features

- Employee attendance tracking
- Employee count dashboard
- Attendance reports
- Basic HR management workflows

## Repository Purpose

This repository is used for demonstrating GitHub workflows such as:

- Issue investigation
- Branch management
- Pull requests
- Repository review activities

The data and examples in this repository are for training purposes only.
